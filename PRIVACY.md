# Privacy Policy for ClearBrowse Ad Blocker

ClearBrowse Ad Blocker was built with a privacy-by-design architecture.

## 1. Information Collection and Use
ClearBrowse Ad Blocker does not collect, record, track, transmit, or monetize any personal information, browsing history, web traffic, IP addresses, or device identifiers.

## 2. Local-Only Processing
- **declarativeNetRequest Rules**: All network request evaluations are handled entirely within the browser's local sandbox.
- **Allowlists**: If you disable blocking on a website, that preference is stored exclusively in your browser's local storage (`chrome.storage.local`) and is never sent to an external server.

## 3. Remote Code Execution
ClearBrowse Ad Blocker does not load external JavaScript libraries or execute remote scripts at runtime.

## 4. Contact
For questions regarding this privacy policy or the extension codebase, open an issue in the public GitHub repository.
