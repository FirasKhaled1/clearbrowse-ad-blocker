# ClearBrowse Ad Blocker

A fast, lightweight, privacy-focused Chrome extension built on Manifest V3. ClearBrowse blocks network ads, trackers, and cleans up page clutter without collecting user data.

## Features
- **Network Request Blocking**: Uses Chrome's `declarativeNetRequest` engine to block third-party trackers before they load.
- **Cosmetic DOM Filtering**: Removes empty ad containers and collapses sponsored elements on Amazon and YouTube.
- **Per-Site Allowlisting**: Easily pause blocking on specific domains with one click.
- **Zero Data Collection**: Operates 100% locally with no telemetry, external analytics, or remote servers.
